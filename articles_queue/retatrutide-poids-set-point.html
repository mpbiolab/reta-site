La théorie du set point : pourquoi les régimes échouent

Le set point pondéral (point d'équilibre pondéral) est la théorie selon laquelle chaque individu possède un 'poids de référence' défendu activement par des mécanismes biologiques. Lorsqu'on tente de perdre du poids par la restriction calorique seule, le corps réagit en réduisant sa dépense énergétique basale et en augmentant la faim — un mécanisme évolutif de survie.

Ce phénomène explique le tristement célèbre effet yoyo : la majorité des personnes ayant perdu du poids par le régime seul en reprennent 80-90% dans les 2-5 ans. Le set point n'a pas changé, et la biologie reprend ses droits.

Comment le Retatrutide pourrait recalibrer le set point

La question cruciale est : le Retatrutide recalibre-t-il le set point, ou supprime-t-il simplement les mécanismes de défense le temps de l'administration ? Les données préliminaires suggèrent une réponse nuancée.

Les études avec d'autres agonistes GLP-1 montrent qu'à l'arrêt du traitement, le poids perdu est partiellement repris, suggérant que le set point n'est pas définitivement modifié. Cependant, la durée et l'amplitude de la perte de poids avec le Retatrutide pourraient permettre des changements structuraux plus durables du tissu adipeux.
